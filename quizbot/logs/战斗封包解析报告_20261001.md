## 一、核心发现：战斗结算包 0x472A

每个客户端每打完一场战斗，服务器都会下发一个 `0x472A` 封包（明文长度 393~403 字节）。

### 明文结构（已实测破译部分）

| 偏移 | 类型 | 含义 | 实测样例 |
|---|---|---|---|
| 0   | i32 | **当前金币余额** | 201785（与 0x40E5 货币更新事件的 a 值一致） |
| 4   | i32 | **本场获得经验值** ★ | 5164（用户口述"一个号一场 5164"，精确命中） |
| 8   | i32 | 0 | |
| 12  | i32 | 0 | |
| 16  | i32 | 0 | |
| 20  | i32 | **本场经验值（重复字段）** | 5164 |
| 28  | i32 | 6（恒定，疑似战斗评价/地图参数） | |
| 32+ | i32 对 | 1006→640（场次相关）、1001（恒定，疑似怪物/地图 ID）、167（恒定）、41015（变动）、59965（变动） | |
| ~140 | i32 数组 | 247/330/-1 等小值（疑似战斗流水/坐标） | |
| 尾部 | 二进制块 | 含 0xFF0000、0xFFFF7B 等疑似飘字颜色值 | |

明文长度 393/403 交替，差 10 字节，为尾部变长段。


## 四、使用方法

```bash
# 抓 10 分钟并自动分析（期间正常游戏）
python tools/battle_capture.py --minutes 10

# 只分析已有的抓包文件
python tools/battle_capture.py --no-cap

# 在全部明文里搜索某个数值（如经验值 5164）
python tools/battle_capture.py --no-cap --find 5164
```

原始封包数据：`build/logs/cap_<pid>.log`（每行 = 时间 + op + 密文 + 解码明文 hex）
自动分析报告：`logs/battle_report_<时间>.md`
